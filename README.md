# Библиотека для аудиоплеера

## Способы интеграции

### Интеграция с помощью внедрения скриптов на существующую HTML-страницу

Этапы интеграции:

1) Добавляем пустой <div> тег с id="multi-audio-player" в необходимое место на сайте.

<div id="multi-audio-player"></div>

2) Добавляем React скрипты на сайт:

<script src="https://unpkg.com/react@18/umd/react.development.js" crossorigin></script>
<script src="https://unpkg.com/react-dom@18/umd/react-dom.development.js" crossorigin></script>

3) Добавляем ниже этих скриптов скрипт из папки dist этого репозитория

<script type="module" crossorigin src="./script.js"></script>

А также выше добавляем стили для этого репозитория:

<link rel="stylesheet" crossorigin href="./style.css" />

Плеер внедрён

Пример интеграции: https://codesandbox.io/p/sandbox/multi-audio-player-qqpt4q
